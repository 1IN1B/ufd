Features

Engineered for Performance

Every feature is designed to maximize download speed and reliability.

Multi-Connection Downloads

Split files into parallel segments across multiple connections, saturating your bandwidth for maximum throughput.

Resume Support

Interrupted downloads pick up exactly where they left off. State is persisted automatically between sessions.

Cross-Platform

Native binaries for Linux, macOS (Intel & Apple Silicon), and Windows. One tool, every platform.

Real-Time Progress

Interactive terminal UI with per-connection progress bars, speed metrics, and ETA estimates in real time.

Interactive Folder Picker

Browse and select download destinations with a built-in keyboard-navigable directory browser.

Error Recovery

Automatic retry on failed connections. Smart error handling keeps downloads moving without manual intervention.

How It Works

Parallel Download Pipeline

UFDLoader breaks files into segments and downloads them concurrently for dramatic speed gains.

01

Range Detection

A HEAD request probes the server for file size and range-request support to determine segmentation strategy.

02

Segment Splitting

The file is divided into equal byte ranges, each assigned to an independent HTTP connection thread.

03

Parallel Fetching

All segments download simultaneously, maximizing bandwidth utilization across every connection.

04

Direct Assembly

Segments write directly to their final byte offsets in the output file. No merge step needed.

Usage

Get Started in Seconds

No config files, no setup. Just run and download.

Basic Download
$ ufdloader https://example.com/file.zip

Downloads with 8 connections by default. Interactive folder picker launches automatically.

Custom Connections
$ ufdloader -c 16 https://example.com/file.zip

Specify the number of parallel connections to use for maximum throughput.

Direct Output
$ ufdloader -o ~/Downloads/file.zip https://example.com/file.zip

Skip the folder picker and download directly to a specified path.

Resume Download
$ ufdloader https://example.com/file.zip

If a partial file exists, UFDLoader automatically resumes from the last byte.
